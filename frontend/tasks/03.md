# Task 03 — Cadastrar Lote, Criar/Editar Dispositivo e Histórico de Leituras

## Objetivo

Implemente 4 telas da área autenticada:

1. **Cadastrar Lote** — formulário para cadastrar um lote em um galpão.
2. **Criar Dispositivo** — formulário para cadastrar um dispositivo em um galpão e exibir o ID gerado para cópia.
3. **Editar Dispositivo** — formulário para alterar dados do dispositivo.
4. **Histórico de Leituras do Dispositivo** — histórico paginado das leituras do dispositivo.

Esta task também deve ativar ações que hoje estão desabilitadas no **Detalhe do Galpão** (cadastrar lote e adicionar dispositivo). Também será adicionada a ação **Ver leituras** na lista de dispositivos do detalhe.

## Endpoints permitidos

Use exclusivamente:

### Cadastrar lote
- `POST /api/galpoes/{galpaoId}/lotes`
  ```json
  { "quantidade": 1200, "dataInicio": "2026-10-01T00:00:00.000Z" }
  ```
- Regras: `quantidade` inteiro maior que 0, `dataInicio` não pode estar no futuro.
- Resposta `201`: lote criado com `status` `ATIVO`.
- Erros: `400`, `404`, `409` (já existe lote ativo), `500`.

### Criar dispositivo
- `POST /api/galpoes/{galpaoId}/dispositivos`
  ```json
  { "nome": "Sensor 1", "modelo": "LDR-01" }
  ```
- Resposta `201` com `id`, `nome`, `modelo`, `status`, `galpoesId`, `criadoEm`, `atualizadoEm`.
- Erros: `400`, `404`, `500`.
- O `id` do dispositivo gerado deve ser exibido em modal acessível para cópia.

### Editar dispositivo
- `PUT /api/dispositivos/{id}`
  ```json
  { "nome": "Sensor 1", "modelo": "LDR-02", "status": "ATIVO" }
  ```
- Campos opcionais; envie `nome`, `modelo`, `status` preenchidos quando possível.
- `status`: `ATIVO` ou `DESATIVADO`.
- Resposta `200` com dispositivo atualizado.
- Erros: `400`, `404`, `500`.

### Histórico de leituras
- `GET /api/dispositivos/{dispositivosId}/leituras?pagina=1&porPagina=20`
- Resposta:
  ```json
  {
    "leituras": [
      { "id": "uuid", "valorLuminosidade": 42, "criadoEm": "2026-10-22T18:00:00.000Z" }
    ],
    "total": 1,
    "pagina": 1,
    "porPagina": 20
  }
  ```
- `porPagina` entre 1 e 100, padrão 20.
- Não existe endpoint para excluir leitura; não implemente.

### Auxiliares
- `GET /api/galpoes` para preencher selects de galpão quando necessário.
- `GET /api/galpoes/{id}` para pré-preencher o galpão no formulário de lote/dispositivo quando vier da rota com `galpaoId`.
- `GET /api/dispositivos` não existe. Não crie rota para listá-los sem galpão.
